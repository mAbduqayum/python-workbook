# Triangle Angle Type

Write a program that determines the type of triangle based on its three angles.

## Triangle Types

| Type             | Condition              |
|------------------|------------------------|
| acute triangle   | All angles `< 90°`     |
| right triangle   | One angle `= 90°`      |
| obtuse triangle  | One angle `> 90°`      |
| invalid triangle | Sum of angles `≠ 180°` |

## Examples

**Example 1:**

```
60
60
60
```

```
acute triangle
```

**Example 2:**

```
90
90
90
```

```
invalid triangle
```
