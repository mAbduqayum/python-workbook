# Exercise: Is It a Leap Year?

Write a program that determines whether a given year is a leap year.

## Leap Year Rules

A year is a leap year if:

1. **Divisible by `400`** → "leap year"
2. **Divisible by `100`** (but not `400`) → "not leap year"
3. **Divisible by `4`** (but not `100`) → "leap year"
4. **All other years** → "not leap year"

## Examples

**Example 1:**

```
2000
```

```
leap year
```

**Example 2:**

```
1900
```

```
not leap year
```

**Example 3:**

```
2004
```

```
leap year
```

**Example 4:**

```
2021
```

```
not leap year
```
