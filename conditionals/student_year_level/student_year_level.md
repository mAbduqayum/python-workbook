# Student Year Level

Write a program that takes a year number (1-4) and returns the corresponding academic year level name.

## Year Levels
| Year | Level     |
|------|-----------|
| 1    | Freshman  |
| 2    | Sophomore |
| 3    | Junior    |
| 4    | Senior    |

## Examples
**Example 1:**
```
1
```
```
Freshman
```

**Example 2:**
```
5
```
```
Invalid year
```
