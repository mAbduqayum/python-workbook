# Student Year Level

Write a program that takes a year number (1-4) and returns the corresponding academic year level name.

## Year Levels
| Year | Level     |
|------|-----------|
| 1    | freshman  |
| 2    | sophomore |
| 3    | junior    |
| 4    | senior    |

## Examples
**Example 1:**
```
1
```
```
freshman
```

**Example 2:**
```
5
```
```
invalid year
```
