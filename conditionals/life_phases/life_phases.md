# Exercise: Life Phases

Write a program that reads a person's age and determines their life phase.

## Life Phase Classifications
| Age Range | Life Phase  |
|-----------|-------------|
| 0-1       | Infant      |
| 2-4       | Toddler     |
| 5-10      | Child       |
| 11-17     | Adolescent  |
| 18-39     | Young Adult |
| 40-64     | Middle-aged |
| 65+       | Senior      |

## Examples
**Example 1:**
```
1
```
```
Infant
```

**Example 2:**
```
-5
```
```
Invalid age
```
