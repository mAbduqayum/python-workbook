# Exercise: Time Hours Converter

Write a program that converts total hours into days, hours, and minutes. Round the total to the nearest whole minute, then split it into days, hours, and minutes, and print them on one line, separated by spaces.

## Examples

**Example 1:**

```
26.5
```

```
1 2 30
```

**Example 2:**

```
10.75
```

```
0 10 45
```

**Example 3:**

```
4.1
```

```
0 4 6
```
