# Exercise: Bank Monthly Interest

Write a program that calculates the balance of a savings account after earning interest compounded monthly.

## Examples

**Example 1:**

```
Enter initial deposit: 1000.00
Enter annual interest rate (%): 4.0
Enter number of years: 3
```

```
1127.27
```

## Formula

`balance = principal × (1 + rate/1200)^(12×years)`
