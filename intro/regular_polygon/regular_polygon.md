# Exercise: Area of a Regular Polygon

Write a program that calculates the area of a regular polygon given the number of sides and the side length in meters.

## Examples

**Example 1:**

```
Enter number of sides: 6
Enter side length: 4
```

```
41.57
```

## Formula

`Area = (n × s²) / (4 × tan(π/n))` where:

- `n` = number of sides
- `s` = side length
