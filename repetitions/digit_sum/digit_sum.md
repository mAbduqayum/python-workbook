# Digit Sum

Calculate the sum of all digits in an integer using loops.

You added the digits of a two-digit number in [Sum of Digits in a Two-Digit Integer](../../intro/sum_digits/sum_digits.md); now use a loop for any number of digits.

## Task
- Read an integer from the user
- Calculate the sum of its digits using a loop
- Display the sum

## Examples
**Example 1:**
```
12345
```
```
15
```
