# Number Pyramid

Create a pyramid pattern using numbers instead of asterisks.

## Task

- Read a positive integer `n` from the user (height of pyramid)
- Display a centered pyramid of `n` rows
- Row `i` starts with `n - i` spaces, then counts up from 1 to `i` and back down to 1

## Examples

**Example 1:**

```
5
```

```
    1
   121
  12321
 1234321
123454321
```
