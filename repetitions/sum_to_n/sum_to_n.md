# Sum to N

Compute the sum of the first `n` positive integers.

You used a formula in [Sum of the First n Positive Integers](../../intro/sum_integers/sum_integers.md); now add the numbers one by one with a loop.

## Task
- Read a positive integer `n`
- Using a loop, compute the sum `1 + 2 + ... + n`
  - Do not use the formula `n * (n + 1) / 2`
  - Do not use the built-in `sum()` function
- Print the total

## Examples
**Example 1:**
```
5
```
```
15
```
