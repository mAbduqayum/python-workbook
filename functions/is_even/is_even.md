# Is Even

Write a function that determines if a number is even.

You wrote this as a program in [Even or Odd?](../../conditionals/even_odd/even_odd.md); now make it a function.

## Task
- Create a function `is_even(n)` that takes an integer
- Return `True` if the number is even, `False` otherwise

## Examples

| Call         | Returns |
|--------------|---------|
| `is_even(4)` | `True`  |
| `is_even(7)` | `False` |
