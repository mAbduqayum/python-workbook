# Decimal to Binary

Write a function that converts a decimal number to binary string.

You wrote this as a program in [Decimal to Binary](../../repetitions/decimal_to_binary/decimal_to_binary.md); now make it a function.

## Task
- Create a function `decimal_to_binary(n)` that takes a decimal integer
- Return the binary representation as a string
- Don't use the built-in `bin()`

## Examples

| Call                    | Returns  |
|-------------------------|----------|
| `decimal_to_binary(10)` | `"1010"` |
| `decimal_to_binary(0)`  | `"0"`    |
