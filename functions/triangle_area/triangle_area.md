# Triangle Area

Write a function that calculates the area of a triangle.

You wrote this as a program in [Area of a Triangle](../../intro/triangle_area/triangle_area.md); now make it a function.

## Task
- Create a function `triangle_area(base, height)` 
- Return the area of the triangle

## Examples

| Call                   | Returns |
|------------------------|---------|
| `triangle_area(10, 5)` | `25.0`  |
