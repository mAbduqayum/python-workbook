# BMI Calculator

Write a function that calculates Body Mass Index (BMI).

## Task
- Create a function `bmi(weight, height)` 
- Weight is in kilograms, height is in meters
- Return the BMI value

## Examples

| Call            | Returns              |
|-----------------|----------------------|
| `bmi(70, 1.75)` | `22.857142857142858` |

## Formula
- BMI = weight / height²
