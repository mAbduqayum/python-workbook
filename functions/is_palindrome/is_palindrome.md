# Is Palindrome

Write a function that determines if a string is a palindrome.

You wrote this as a program in [Is a String a Palindrome?](../../repetitions/palindrome/palindrome.md); now make it a function.

## Task
- Create a function `is_palindrome(s)` that takes a string
- Return `True` if it reads the same forward and backward, `False` otherwise

## Examples

| Call                       | Returns |
|----------------------------|---------|
| `is_palindrome("racecar")` | `True`  |
| `is_palindrome("hello")`   | `False` |
| `is_palindrome("")`        | `True`  |
